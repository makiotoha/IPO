# 📈 A股新股申购日历自动化同步

本项目通过 GitHub Actions 在每天 18:00 自动拉取最新的 A 股新股申购数据，生成标准 `.ics` 日历文件并通过 GitHub Pages 发布。你可以通过任何支持网络日历订阅的手机订阅该日历，在申购日**上午 09:30** 自动接收弹窗/响铃提醒。

---

## 🔗 日历订阅地址

将以下链接直接复制并添加到手机日历的 **网络日历/URL订阅** 中：

```text
https://makiotoha.github.io/IPO/ipo.ics
```

---

## 📱 手机订阅教程

1. 打开手机自带 **日历** 应用。
2. 点击左上角菜单，进入 **日历账户管理** 或 **添加订阅**。
3. 选择 **通过 URL 订阅** 或 **网络日历**。
4. 粘贴上面的订阅链接，并完成添加。
5. 设置同步频率（建议设置为“每天”或“自动”）。

---

## 🛠️ 项目自动化工作流说明

- **执行时间**：每天北京时间 18:30（对应 UTC 时间 10:00）。
- **运行逻辑**：
  1. 调用迈瑞 API 获取最新 A 股新股申购列表（`stocks.json`）。
  2. 运行 `generate_ics.py` 将今天及未来的新股申购数据转为标准 `ipo.ics` 文件。
  3. 自动提交并发布至 GitHub Pages。
- **提醒格式**：
  - **日程标题**：`今日申购：XXXX`
  - **提醒时间**：申购当天上午 `09:30`

---

## 📁 项目关键文件列表

* `.github/workflows/sync.yml` - GitHub Actions 定时任务配置
* `sync_mairui.py` - 获取迈瑞 API 新股数据的 Python 脚本
* `generate_ics.py` - 解析 JSON 数据并过滤生成 ICS 日历文件的 Python 脚本
* `stocks.json` - 原始新股数据文件
* `ipo.ics` - 最终用于手机订阅的日历文件
